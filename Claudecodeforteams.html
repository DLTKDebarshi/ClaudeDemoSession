Install Claude Code

Never used a terminal? Follow the steps for your OS — takes ~3 minutes. Adapted from the official Claude Code terminal guide ↗

Option A

🍎 macOS & Linux

Requires macOS 13.0+
  1. Open Terminal — Cmd + Space, type Terminal, press Enter. (Linux: Ctrl + Alt + T.)
  2. Install Claude Code — paste this line and press Enter:
    curl -fsSL https://claude.ai/install.sh | bash
    Wait for “Claude Code successfully installed!”
  3. Start Claude Code:
    claude
    A browser window opens — sign in with your Claude account.
  4. You're in. Type a message and press Enter. Use Esc to interrupt, /help for commands, exit to quit.
Option B

🪟 Windows

Requires Windows 10 (1809)+
  1. Install Git for Windows (optional but recommended) — download from git-scm.com/downloads/win and click Next through every screen.
  2. Open PowerShell — press Win + X, choose Windows PowerShell (or Terminal). Confirm the prompt starts with PS — not plain CMD.
  3. Install Claude Code — paste and press Enter:
    irm https://claude.ai/install.ps1 | iex
    In CMD instead? Use: curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd && del install.cmd
  4. Close and reopen PowerShell so it picks up the new claude command, then run:
    claude
    Sign in via the browser window that opens.
  5. You're in. Same shortcuts: Enter to send, Esc to interrupt, /help, exit to quit.

💡 Prefer no terminal?

Use the Claude Code desktop app or the VS Code / JetBrains extensions instead — same Claude, zero command line.

⬇ macOS app ⬇ Windows app
🛠 Hit an error? Common fixes: re-open the terminal so claude is recognized · on macOS make sure you're on 13.0+ · on Windows run PowerShell (not CMD) for the irm command. Full guide → troubleshoot-install.

Live Demo Guide

Three progressively deeper demonstrations — each showing a different Claude Code superpower

Demo 1

Operational Runbook Generation

⏱ ~2–3 min  ·  Chat Mode

Drop one prompt and watch Claude read 25+ files — source code, Terraform, Docker, CI config, migrations, monitoring — then produce a complete ops runbook.

  • Stay in default Chat mode (no mode switch needed)
  • Run the "Operational Runbook" prompt from the guide
  • Watch Claude traverse the whole codebase
  • Check: env vars from code and docker-compose and Terraform?
  • Check: incident INC-2843 surfaced in failure modes?
What to highlight: Multi-file reasoning across 25+ files in under 3 minutes — something no human could match in speed.
Demo 2

Incident Command Center

⏱ ~3–4 min  ·  Plan Mode → Execute

Two-phase live coding: first Claude plans the architecture (review it out loud), then builds a fully functional dark-themed Incident Command Center HTML page.

  • Switch to Plan Mode: Shift+Tab twice or /plan
  • Run Phase 1 — reads postmortem, handoff & change log
  • Review the plan with the audience (~1 min)
  • Exit plan mode, run Phase 2: "The plan looks good, build it"
  • Open the generated HTML in browser live
What to highlight: Plan Mode = human oversight before any files are touched. The audience sees AI + control.
Demo 3

Database Migration Plan

⏱ ~1–2 min  ·  Plan Mode

Claude reads a 21 GB / 34%-bloat database health report and slow-query log, then plans a safe partition migration with exact SQL, risk assessment, and rollback for each step.

  • Stay in Plan Mode from Demo 2
  • Run the "Database Migration Plan" prompt
  • Claude reads: schema + health report + slow query CSV
  • Output: SQL per step, locking risk, rollback, maintenance window
  • Fast demo — pure planning, no files written
What to highlight: DBA-level reasoning from 3 data sources in 90 seconds — with rollback instructions baked in.

⌨️ Essential Keyboard Shortcuts & Commands

Shift+Tab (×2)

Cycle permission modes: Approval → Auto-Accept → Plan Mode

Esc

Interrupt Claude mid-response if it's heading in the wrong direction

/plan

Jump directly into Plan Mode — Claude will plan before touching any file

/init

Auto-generate a CLAUDE.md from your current codebase

/compact

Free up context window if Claude seems slow or forgetful

/help

Show all available Claude Code commands at any time
